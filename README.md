# Product page

QR landing page for Business Brain, Joya, Beto and Qsor. React 18 + Vite + Tailwind CSS 4.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

Product content, links and brand colours live in `src/products.js`. Logos are in `public/logos/`.
Deploy `dist/` to any static host (Vercel, Netlify, etc.) and point the QR code at that URL.
